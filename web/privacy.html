Komitmen Privasi Kami

Rolling Jungle Run dibuat untuk dimainkan dengan tenang. CV Cahaya Asia Bersama tidak meminta, mengambil, atau memindahkan informasi pribadi pemain. Fokus kami hanya menghadirkan pengalaman bermain yang ringan dan menyenangkan.

01

Game Tanpa Profil dan Pelacakan

Anda dapat langsung masuk ke permainan tanpa membuat akun atau mengisi data diri. Tidak ada formulir, sistem login, iklan, analytics, GPS, maupun alat pemantau aktivitas yang disisipkan ke dalam game.

02

Progres Berhenti di Perangkat

Skor, level, pilihan audio, dan pengaturan permainan disimpan secara lokal agar game dapat mengingat kemajuan Anda. Informasi tersebut tidak dikirim ke server, tidak masuk ke cloud, dan tidak dapat kami lihat.

03

Anda Memegang Kendali

Semua data permainan berada di tangan Anda. Jika ingin menghapusnya, buka Pengaturan → Aplikasi → Rolling Jungle Run → Bersihkan Data / Cache. Menghapus aplikasi juga akan menghilangkan seluruh data lokal yang tersimpan.
